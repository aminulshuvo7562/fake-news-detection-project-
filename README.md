======Fake News Detection Project======

This project is part of the Introduction to Data Science course. The main goal is to analyze fake and real news using R programming and machine learning.

## Dataset
- Fake News: 2,000 articles
- Real News: 2,000 articles
- Total: 4,000 articles

## Project Objectives
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Data Visualization
- Feature Engineering
- Machine Learning Classification
- Model Evaluation

## Tools
- R
- RStudio
- R Markdown

## Purpose
To identify patterns in fake and real news and develop a machine learning model for news classification.

**Status:** Work in progress.
